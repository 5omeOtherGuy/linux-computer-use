# Internal engine contract

Clean-room implementation. Do not inspect or copy proprietary implementation artifacts. Public API shapes and the supplied research specification are inputs, not implementation source.

Engine stdin/stdout: one JSON object per line. Request `{id, method, params}`; response `{id, result}` or `{id, error: {code, message, data?}}`. stdout is protocol only. Each daemon is one session bound to one explicit non-`:0` display and private accessibility bus. The only exception is the command-line opt-in `--live-desktop --allow-app APP_ID [--allow-app ...] [--pid PID ...]`, which may use `:0` but lists only windows of the allow-listed apps (and PIDs) whose client PID the X server reports; it cannot be enabled from the environment. Methods: `list_apps`, `list_windows`, `get_app_state`, `get_ax_state`, `get_screenshot`, `click`, `drag`, `scroll`, `type_text`, `press_key`, `paste`, `set_value`, `perform_secondary_action`, `approve_app`, `turn_ended`. Params use snake_case. Window methods require `window_id` integer. Click/scroll use `element_index` or `x,y`; drag uses `from:[x,y],to:[x,y]`; scroll uses `direction,pixels`; text methods use `text`; press_key uses `key`; set_value uses `element_index,value`; secondary action uses `element_index,action`. Coordinates are window-local pixels. Actions return post-action observation, not void. Observation `{window, accessibility, ax_diff, screenshot?, timing:{settle_ms, observation_ms}, warnings:[]}`. Screenshot `{data:base64,mimeType:"image/png",width,height}`. Apps/windows contain `{window_id,title,app_id,pid,width,height}`; `pid` is the X-Resource `LocalClientPID` of the client that created the window (0 if unknown), never `_NET_WM_PID`. `type_text` and `paste` require non-empty `text`. Element IDs are unique for the daemon session and never reused. After an action, a `No UI reaction` warning means no damage, popup map or AT-SPI event arrived within the reaction bound. `get_screenshot` returns the screenshot directly. `get_ax_state` returns observation. Unknown/unimplemented methods fail explicitly.

Authorization is enforced by the daemon, before read or write of a window. Error `approval_required` has `data:{app_id,window_id,title}`. Trusted surface sends `approve_app {window_id,app_id}` only after successful MCP elicitation or a session/always decision the user made earlier. Deny overrides allow and approval; a window whose process identity or executable cannot be established is denied. Raw daemon is a trusted host API, never directly exposed to model code. `turn_ended` clears daemon approvals, observation state, the input-abort latch, virtual cursors and hover state. Confirmation-policy metadata is surfaced, not interpreted as an enforcement engine.

Rust module boundaries:

* `x11.rs`: `pub struct Desktop`; `Desktop::connect(display: &str)->anyhow::Result<Self>`; `Desktop::connect_live(display,LiveScope)`; `list_windows(&mut self)->Result<Vec<WindowInfo>>`; `window(&self,id:u32)->Result<WindowInfo>` (resolve once per request and pass the `WindowInfo` down); `track(&mut self,&WindowInfo)` (eager Composite redirect + damage); `screenshot(&mut self,&WindowInfo)->Result<serde_json::Value>`; `prepare_action(&mut self,&WindowInfo)`; `action(&mut self,&WindowInfo,method:&str,p:&Value)->Result<()>` (click, drag, scroll, press_key); `settle(&mut self,react,quiet,cap,external:&mut dyn FnMut()->bool)->Result<Settled{reacted,quiet}>`; `check_user_input(&mut self)->Result<()>`; `end_turn(&mut self)->Result<()>`. WindowInfo derives Serialize, Clone, Debug with public fields `window_id:u32,title:String,app_id:String,pid:u32,width:u16,height:u16`. No global XTEST input. Background send-event plus window-local virtual cursor; hit-testing covers the window and its client's popups and refuses subwindows of other clients. Track physical XI2 raw input and latch abort. Module owns X event settling and capture. Deny display :0 except in live mode.
* `ax.rs`: `pub struct Accessibility`; `async fn connect()->Result<Self>`; `async fn snapshot(&mut self,window:&WindowInfo)->Result<AxSnapshot>`; `async fn action(&mut self,window:&WindowInfo,method:&str,p:&Value)->Result<()>`; `fn reset(&mut self)` (keeps the session-wide ID counter); `fn activity_probe(&self,&WindowInfo)->impl FnMut()->bool` (AT-SPI events of the window's app since the probe was made). `AxSnapshot` has public `text:String,diff:String,warnings:Vec<String>`. Use zbus cache and event invalidation, window-bound IDs. AX failures are explicit warnings for observation; semantic action errors must never fall back to arbitrary input or to an arbitrary AT-SPI action.
* `main.rs` (parent-owned): NDJSON, policy, orchestration, deadlines and observations. `policy.rs` parent-owned.
* `surface/` (surface-worker-owned): MCP server, isolated persistent JS runtime, discrete tools, provider adapters, tests. Spawn daemon from `CUA_ENGINE` (default target/debug/linux-cua) with inherited explicit `CUA_DISPLAY` and no arguments; daemon accepts environment `CUA_DISPLAY`, `CUA_ALLOW_APPS` and `CUA_DENY_APPS` comma-separated exact app IDs, and `CUA_ALLOW_ABSTRACT_BUS=1`. The model-facing JS API uses OpenAI's names and shapes (`WindowInfo {id, app, title?}`, `AppInfo`, `nodeRepl`); `window_id` stays on the NDJSON side. REPL may call only exposed API, never raw `approve_app`. Host validates/re-authorizes every call. Timeout cancels/restarts engine to prevent late actions.

No module should pretend unsupported features succeeded. Tests should verify observable results and safety boundaries. No agent edits another worker's files or launches a GUI; parent owns private display and integration benchmark. Build artifacts go under `/data/scratch/linux-cua-build/target` using CARGO_TARGET_DIR, builds use CARGO_BUILD_JOBS=2.
